# V1.3 内容新鲜度与留存验证 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将每周主题扩展为可体验的主题卡包，并加入无身份的一键内容反馈。

**Architecture:** 扩展现有 `data/weekly.js` 为主题卡包，周服务派生稳定卡包和进度；本周星光页面复用 `action-followup` 展示三张卡；research 服务增加周主题事件，仍然只做本机聚合记录。

**Tech Stack:** 原生微信小程序、JavaScript、WXML、WXSS、Node.js 回归脚本。

**Spec:** `docs/superpowers/specs/2026-11-08-v1.3-content-pack-design.md`

## Global Constraints

- 不新增账号、云端同步、广告和分享协议字段。
- 每周主题按 ISO 周编号稳定轮换。
- 主题卡最多 3 张，每张使用现有行动记录机制。
- 调研默认关闭，不记录身份、私人问题和完整结果。
