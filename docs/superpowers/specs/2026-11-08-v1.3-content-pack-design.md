# V1.3 内容新鲜度与留存验证设计

## 意图

V1.2 已经提供本周星光回顾，但周主题目前主要是一段说明文字。本版将每周主题扩展为一个轻量主题卡包，让用户每周回来时有新的内容可以体验，同时用一键反馈验证内容是否真正有帮助。

## 目标

- 每周主题包含 3 张原创主题卡，每张都能收下一个行动。
- 同一设备同一周主题卡包稳定，跨周自动轮换。
- 本周星光页面展示卡包内容和主题进度。
- 用户可以对本周主题做一键反馈：有帮助 / 换个角度。
- 调研事件保持本机、默认关闭、只记录聚合次数。
- 保持既有卡片、行动、分享和历史协议兼容。

## 非目标

- 不做云端同步、账号、评论和广告。
- 不改变普通牌阵、答案之书和双人匹配算法。
- 不把主题包做成付费或稀有度系统。

## 体验结构

本周星光页面顺序：本周主题 → 三张主题卡包 → 本周统计 → 最近行动 → 一键反馈 → 今日/骰子/双人入口。

主题卡使用 `weekly-pack` 类型和本机行动记录保存。卡包内容不进入既有分享链接，避免扩展分享协议；用户仍可以通过现有海报和普通卡牌分享核心结果。

## 验收标准

- 6 个原创主题包可按周稳定轮换。
- 每个主题包有 3 张卡，卡片可保存并标记完成。
- 页面显示主题包已收下 / 已完成进度。
- 反馈按钮只记录事件次数，不记录用户选择以外的内容或身份信息。
- 375rpx、390rpx 不横向溢出。
- 现有 90 项回归和新增内容包测试全部通过。
