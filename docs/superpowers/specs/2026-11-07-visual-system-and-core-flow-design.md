# 星座卡牌视觉系统与核心流程优化设计

## 意图

当前小程序已经拥有每日星座卡、今日主签、普通牌阵、答案之书、双人星图和吉运骰子，但首页入口较多，部分命名与真实行为不完全一致，颜色和动效也存在页面级重复定义。本版的目标是让用户更快理解产品价值，并让“卡牌结果 → 一个小行动”成为稳定的使用循环。

核心表达：

> 先照顾此刻，再往前一步。

## 目标

- 首页优先呈现三条主路径：今日方向、双人关系、一件小行动。
- 明确区分“今日星座卡”和“今日主签”，避免按钮文案与实际跳转不一致。
- 将双人星图保留为核心传播入口，并强化其到“小约定”的承接。
- 将吉运骰子从“吉凶工具”调整为“星光骰子 / 行动方向工具”的体验表达。
- 建立统一的颜色、圆角、边框、字号和动效变量，减少页面之间的视觉漂移。
- 通过暗紫局部强调星空感，但不破坏原有松绿、暖白、金色的克制气质。
- 保持原生微信小程序、无新增运行时依赖、低资源动效和现有数据兼容。

## 非目标

- 本版不新增登录、云端同步、社区或付费系统。
- 本版不接入真实广告，也不改变广告默认关闭状态。
- 本版不重写牌库、答案之书内容或匹配算法。
- 本版不把所有页面改成紫金色，也不引入大面积高饱和紫色渐变。

## 反目标

- 不让首页继续承载所有功能入口。
- 不把骰子包装成确定性的运势或吉凶判断。
- 不使用 Emoji 作为功能型图标。
- 不用更复杂的动画掩盖信息层级问题。
- 不牺牲低端设备和减少动效模式下的可用性。

## 方案比较

### 方案 A：全量紫金星象主题

全局切换为深紫、亮紫和金色，强化塔罗和占卜氛围。视觉冲击较强，但容易与普通玄学模板同质化，正文对比和长期阅读舒适度也更难控制。

### 方案 B：继续保持现有松绿暖白金色

只做布局、命名和骰子交互优化，风险最低，品牌连续性最好，但星图和骰子缺少进一步的夜空层次。

### 方案 C：松绿暖白金色为主，暗紫局部强调（采用）

保留现有品牌识别，在启动页、骰子舞台、双人星图的星空层和选中状态中加入暗紫。该方案兼顾原有的简约高级感、治愈感和星空神秘感，改动风险可控。

## 视觉系统

基础色：

- 暖白背景：`#F4F2EC`
- 卡片表面：`#FCFBF7`
- 深松绿主色：`#233F39`
- 正文深绿：`#283C33`
- 低饱和金色：`#B5A179`
- 暗紫强调：`#342C46`
- 柔和紫灰：`#8A7A9C`
- 低对比边框：`#D9DCCF`

暗紫只用于星图、骰子舞台、启动动效和少量状态强调；正文和主按钮仍以深松绿为主。

统一变量：

- 圆角分为 12 / 16 / 24rpx 三档。
- 间距按 8rpx 节奏收敛。
- 交互控件最小触达区域保持 88rpx 左右。
- 动效分为 fast / standard / ritual 三档，并继续支持 reduced motion。

## 页面与流程调整

### 首页

- 首屏保留今日星座卡，并将标题和说明继续围绕“给今天一个方向”。
- 主按钮明确为“抽一张今日主签”，不再使用容易与首页星座卡混淆的“收下今日卡牌”。
- 双人星图和星光骰子保留为两张重点入口卡，答案之书与趣味测试降为探索内容。
- 主题抽卡、答案之书和趣味测试集中到“再给自己一个角度”区域，降低首屏决策压力。

### 抽卡页

- 继续保留今日主签、星光牌阵、答案之书和星光骰子，但将四项入口改成更稳定的分组或两行布局，避免小屏横向拥挤。
- 文案明确“今日主签”和“自由探索”的差异。

### 双人星图

- 保留现有双方星座、关系类型和三张牌流程。
- 结果页突出“下一步靠近”，把星光骰子作为“小约定”承接。
- 关系解读继续使用定性维度，不增加分数或确定性结论。

### 星光骰子

- 产品文案从“吉运骰子”逐步调整为“星光骰子”，六个面继续对应出发、松弛、表达、尝鲜、整理、温暖。
- 骰子结果先展示“你摇到的是：某个方向”，再展示一条可执行行动，最后进入完整卡牌结果。
- 单人结果强调今天的一件小事，双人结果强调一个低压力的小约定。
- 3D 骰子保留，但减少舞台空白和重复轨道，补充落地光圈、轻震动和静态降级表现。

## 验收标准

- 首页用户能在首屏理解今日卡、双人星图和星光骰子的用途。
- 今日星座卡与今日主签在名称、入口和结果上不再混淆。
- 375rpx、390rpx 手机宽度下不出现横向溢出，四项抽卡入口可读可点。
- iOS 与 Android 的功能型箭头和图标表现一致。
- 骰子完整动画、跳过动画和减少动效模式均可正常使用。
- 颜色变量集中管理，页面不再重复写互相冲突的基础色。
- 现有 78 项回归检查保持通过，历史结果、分享链接和本地收藏不受影响。
