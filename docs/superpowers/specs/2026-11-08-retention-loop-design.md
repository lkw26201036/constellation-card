# 留存闭环与星光回响设计

## 意图

当前小程序已经能给用户每日卡、牌阵、双人星图和星光骰子，但结果页结束后缺少一个轻量的后续动作。本轮先解决第一次使用到第二次使用的衔接，再为双人星图增加无账号的回应体验。

核心循环：

> 收下一张卡 → 选一个小行动 → 标记完成或稍后 → 下次回看 → 邀请朋友一起回应

## 本轮目标

- 结果页可以保存一条“收下的小行动”。
- 用户可以将行动标记为“已完成”或“稍后再做”。
- 首页可以回看最近一条未完成或最近完成的行动。
- 本机记录不包含私人问题、性别描述、昵称或完整分享链接。
- 双人星图可以生成一条无账号、无云端的“星光回响”分享入口。
- 朋友打开回响入口后，可以选择一个回应并生成自己的回应卡。

## 非目标

- 本轮不做云端同步、回应收件箱或账号体系。
- 本轮不做公共评论、关系排行榜或强制签到。
- 本轮不接入广告，不改变既有牌库、匹配算法和分享协议。

## 方案

### 本机行动记录

新增独立的 `actions` 服务，最多保存最近 60 条行动记录。每条记录只保存：卡片 ID、类型、标题、行动文本、日期、状态和时间戳。状态为 `saved`、`done` 或 `later`。

页面通过 `action-followup` 组件展示状态：

- 未记录：收下这一步；
- 已保存：标记为已完成 / 稍后再做；
- 已完成：显示完成时间，并允许改为稍后再做；
- 稍后再做：显示继续完成入口。

### 星光回响

双人结果页新增“邀请对方留下回应”。分享链接只携带可公开还原双人结果所需的参数。朋友在 `pages/echo/echo` 选择三种回应之一，设备本地生成回应卡并可继续摇一次星光骰子。

第一版不承诺把回应同步回发起者；页面文案明确这是朋友自己的回应体验，避免制造云端同步预期。

## 验收标准

- 今日卡、双人星图和星光骰子结果都可以收下行动。
- 重新打开小程序时，首页能看到最近行动入口。
- 清理本地数据后行动记录消失，不影响既有卡片历史和分享链接。
- 双人回响入口在不同设备可打开，且不分享昵称、性别和私人信息。
- 回响回应卡不改变原双人卡内容，原分享链接仍能正常还原。
- 现有回归测试全部通过，减少动效模式不影响操作。
