# V0.8.0 · 双人星图与吉运骰子

实现状态：本地开发完成，已完成自动回归与微信开发者工具流程验证。安卓/iOS真机动画、真实转发和保存图片仍需体验成员验收。

## 双人星图

- 入口：首页“​​双人星图”、普通牌阵页的模式入口。
- 选择双方星座和关系类型：心动探索、恋爱相处、朋友相处。自己的已绑定星座自动带入；本次选择不修改个人绑定。
- 昵称、同性/异性描述是选填项，只保存在本机，不参与匹配规则、不进入分享链接或海报。
- 双人牌阵仍为七选三，沿用60张原创牌库、最近四局避重、撤回、跳过、减少动效、草稿恢复和整组保存。
- 三个牌位为“彼此的连接、值得留意的差异、下一步的靠近”，每张牌使用专门的双人关系文案。
- 结果按双方星座与关系类型生成三个维度：交流节奏、情绪回应、行动步调，并给一句关系总结。没有百分比、排名或吉凶等级。
- 基础关系提示保持稳定，三张牌决定本次探索角度。文案使用可能性和建议，不断言对方真实想法、关系结果或未来。
- 双人揭晓动画从两束星光靠近开始，再进入牌扇、三张牌阵和结果阅读。

## 吉运骰子

- 入口：首页“吉运骰子”、抽卡页模式、双人牌阵结果的“摇出你们的小约定”。
- 六面骰对应六种行动方向：出发、松弛、表达、尝鲜、整理、温暖；点数不代表运气高低。
- 单人模式使用60条原创建议，双人模式使用60条原创小约定。每面10条，按近期同面结果避重。
- 骰面包含清晰星点、星座/十二星光纹样和统一的深松绿暖金材质。
- 动画包含多轴翻滚、起跳、阴影变化、弹跳落地、点数亮起与结果渐显；可跳过，减少动效设置生效。
- 双人骰子关联原牌阵编号和日期，用牌阵中对应牌的提示、匹配维度和关系类型生成一条小约定。
- 骰子结果可收藏、回看、生成海报和分享；首页单人结果不要求填写星座，未绑定访客显示十二星光。

## 隐私、兼容与分享

- 分享前增加预览页。双人分享只展示双方星座、关系类型、公开牌面和解读，不展示选填昵称、性别描述或私人问题。
- 接收者打开分享不会改变自己的星座绑定；双人结果和骰子结果可按版本、双方星座、关系、编号与日期还原。
- 卡册新增双人星图和骰子分类；旧v1/legacy/t1/t2/q1/u1/s1/b1结果与旧分享继续可读。
- 研究模式仍默认关闭；开启后只记录pair_start、pair_complete、dice_roll等聚合事件，不记录双方星座、关系、昵称、性别、牌号或骰子编号。
- 广告配置仍默认关闭，核心结果不要求看广告。

## 真机验收

1. 开发者工具上传版本号`0.8.0`，设为体验版。
2. 安卓与iOS检查星图相遇、牌阵翻面、骰子翻滚落地和结果渐显；测试跳过、减少动效、切后台返回。
3. 填写双方星座和关系，确认三个维度和一句总结与关系类型匹配；检查昵称/性别不会出现在分享预览。
4. 从双人结果摇小约定，检查骰子结果能回看、收藏并还原原牌阵日期。
5. 生成双人海报和骰子海报，确认内容不截断；通过体验成员真实转发验收接收页。
