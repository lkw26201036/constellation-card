# V1.2 · 本周星光回顾与主题进度

## 本版目标

让用户每周都有一个自然的回访理由：看到这一周留下的方向、完成的小行动和一个正在轮换的主题。

## 已完成

- 新增“本周星光”页面。
- 每周主题按 ISO 周编号本地稳定轮换，共 6 个原创主题。
- 展示本周收下的小行动、完成的小行动和收藏卡片数量。
- 展示本周最近三条行动，可继续标记完成或稍后再做。
- “我的”和“卡册”增加本周星光入口。
- 无行动数据时使用温和空状态，不强迫用户签到。
- 统计只使用当前设备已有记录，不新增账号、云端同步或广告。

## 验证

```powershell
node tests/run.cjs
```

本版回归包含 ISO 周边界、主题稳定性、行动统计、收藏统计、空状态和窄屏入口检查。
