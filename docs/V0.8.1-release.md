# V0.8.1 · UI排版与体验优化

## 完成内容

- 首页新增玩法区域改为两列卡片：三张星光、答案之书、双人星图、吉运骰子，保持等宽、等边距和统一点击区域。
- 双人星图设置页与骰子结果页使用同一套轻量原生排版，双人结果操作按钮在窄屏下不再被宽度撑开。
- 吉运骰子重新设计视觉：浅纸张背景、中央星盘舞台、柔和轨道、深松绿金边骰体、星点/星图纹样、落地阴影和结果层级。
- 保留骰子多轴翻滚、起跳、弹跳、落地光圈和减少动效；无图片、视频、外部字体和新增运行时依赖。
- 产品内版本文案从“体验版”调整为“版本”，保留必要的娱乐提示与分享隐私说明。

## 验证

- 模拟器检查首页两列卡片和骰子页新视觉；骰子结果仍能显示点数、行动方向和小行动。
- 既有逻辑未改变，双人星图、骰子、牌阵、答案之书和旧内容继续使用原版本规则。
