# V1.4 七日星光旅程

发布日期：2026年11月8日

V1.4 把一次性的抽卡体验延伸成七天的小行动旅程，让用户每天只做一件很小的事，并在第七天得到一张温和的回望总结。

## 本次内容

- 首页新增七日星光旅程入口。
- 旅程固定包含 7 张原创行动卡，按日期和完成进度逐张解锁。
- 每张卡支持收下、完成和稍后再做。
- 用户中断后可以继续，错过日期不会清零，也不会一次性解锁多张卡。
- 未绑定星座的用户可以直接开始，切换星座不会改变旅程内容。
- 第七天完成后生成公开总结卡，支持收藏、海报和分享。
- 最近 5 轮已完成旅程的摘要保存在本机，重新开始不会覆盖历史摘要。

## 数据边界

- 旅程状态保存在当前设备的 sevenDayJourney 本地存储中。
- 总结分享只包含旅程开始日期、完成日期和版本，不包含昵称、性别、星座选择历史、完成时间或本机调研记录。
- 本机体验记录默认关闭；开启后只按日期统计 journey_start、journey_open、journey_day_complete、journey_resume、journey_complete 和 journey_summary_share。
- 本版本不接入账号、云端同步、广告或付费能力。

## 微信开发者工具验收

1. 编译后进入首页，确认能看到“七日星光旅程”入口。
2. 点击开始，确认显示第 1 / 7 天和第一张行动卡。
3. 收下并完成行动，确认当天不会自动出现第二张卡。
4. 修改开发者工具日期到下一天，重新进入旅程，确认解锁下一张卡。
5. 连续完成第七天，确认出现“七日星光总结”，可以打开海报页。
6. 在另一台设备打开分享链接，确认能看到同一张公开总结，不要求本地已有旅程记录。
7. 开启本机体验记录后再重复操作，确认只出现聚合事件。
