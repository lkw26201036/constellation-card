# V1.3 内容新鲜度与回访验证

发布日期：2026年11月8日

V1.3 用一组每周更新的主题卡包，让用户在完成一次抽卡后有明确的回访理由，同时用轻量反馈验证内容方向是否值得继续投入。

## 本次内容

- 每个 ISO 周主题包含 3 张原创主题卡，卡片带有标题、解释和一件可执行的小行动。
- 周报页显示本周卡包、已完成数量、本周行动统计和最近留下的方向。
- 卡包卡片复用现有“收下 / 完成 / 稍后再做”行动组件，完成后会即时更新进度。
- 周报页提供“有帮助”和“换个角度”两个反馈入口，反馈只给出感谢提示，不阻塞继续使用。

## 数据边界

- 卡包内容按 ISO 周稳定选择，同一周在同一设备上保持一致，跨周自动轮换。
- 反馈和周报事件只有在用户主动开启“本机体验记录”后才计数。
- 记录仅保存日期与事件次数，最多保留 30 个记录日；不保存反馈选项、问题文本、卡片编号、星座组合或身份信息。
- 本版本仍不接入账号、云端数据库、广告和付费能力，核心内容不依赖广告。

## 验证

使用微信开发者工具打开“我的 → 本周星光”，检查周主题卡包是否显示 3 张卡、完成一张后进度是否更新，再分别点击两个反馈按钮。开启本机体验记录后，可在体验记录页确认周报相关事件只显示聚合计数。

自动回归：`node tests/run.cjs`。
