# V1.1 · 留存闭环与星光回响

## 本版目标

让用户第一次使用后还有一个自然的后续动作，并让双人星图从单向分享变成朋友可以参与的轻量回应。

## 已完成

- 今日卡、双人星图和星光骰子结果支持“收下这一步”。
- 行动支持保存、标记已完成和稍后再做。
- 本机最多保存最近 60 条行动记录，不保存私人问题、昵称、性别或完整分享链接。
- 首页显示最近一次不是当前卡片的小行动，帮助用户回看上次留下的方向。
- 双人星图增加“邀请对方留下回应”。
- 新增无账号、无云端的星光回响页面，朋友可以选择三种回应并生成自己的回应卡。
- 回响页面可以继续分享回应卡或重新展开自己的双人星图。

## 边界

本版不做回应同步回发起者、不做账号体系、不做公共评论和广告。星光回响只在打开它的设备上生成回应，后续会根据真实使用量决定是否增加云端收件箱。

## 验证

```powershell
node tests/run.cjs
```

本版回归包含行动记录状态流转、60 条上限、重启恢复、星光回响公开路径、隐私字段排除和既有分享兼容性。
