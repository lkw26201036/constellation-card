# V0.6.2 · 首次访客与通用星图

## 行为
- 无有效星座存储时保持未绑定，空值/未知值不再回落到双鱼座。
- 通用启动星图：十二颗外围星点依次亮起、连成环，中央星光与四条连接随后出现。保持深松绿与金色、约2秒、可跳过、减少动效支持。
- 已绑定时仍使用对应的十二星座专属星图。
- 首页未绑定时显示今日灵感卡，说明选择星座的作用；不要求登录或生日。
- 未绑定也能完成主签、自由主题、测试、收藏、卡册、海报与分享。通用卡底部为品牌星图，不出现双鱼座专属信息或幸运色/数。
- 选择星座仅影响后续生成内容；已抽当天主签、历史与收藏不会改写，每日设备配额保持。
- 分享结果按链接还原，不自动绑定接收者星座。旧首页 sign 参数不再执行静默绑定。
- 我的 → 启动动效 → 预览，新增“首次访客 / 我的星座”切换；不修改绑定存储、不改启动记录。未绑定时个人预览提示先选择。

## 内容与兼容
- 新增通用日卡内容版本 u1，独立 ID；既有 v1/legacy 日卡内容与链接保留。
- 主签/主题卡/测试沿用原内容版本，新增合法“通用”身份；分享仍还原原结果。
- 未修改原14主题与24张主题卡文案。通用灵感按日期轮换，仍可能重复。
- 不猜测旧双鱼座记录是否用户主动选择，保留已有合法选择。
- 无广告、账号、云端或新增依赖。

## 验证
- node tests/run.cjs：42组通过。覆盖无/空/无效/已清理存储、通用结果分享往返、绑定后配额保持、个人内容兼容、双模式预览不写存储等。
- 微信开发者工具：重新打开项目编译，调试器0错误；手动检查个人星图、首次访客十二星光、预览切换与页脚布局。
- 开发工具模拟器保留已有绑定记录，未清理用户数据。无绑定首页/抽卡/测试由独立存储的逻辑回归验证。
- 真机首次进入、转发接收、图片保存仍建议验收；本动画是页面可执行后的品牌序章，不能替代微信系统初始化加载。
