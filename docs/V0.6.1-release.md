# V0.6.1 星图启动序章

## 视觉

沿用深松绿、暖金与中文衬线字。启动时星点依次亮起，连成对应星座的装饰星图；刻度环只扫过一轮，最后淡出进入首页。无视频、无图片下载、无额外依赖；使用原生view和CSS的transform/opacity动画。

## 行为

- 默认入口为pages/launch/launch，约2秒后进入原首页。首页仍是原生Tab页。
- “直接进入”立即结束；减少动效开启时直接进入首页。
- 返回前台不重复拦截首页；分享链接仍直达原页面，未修改分享路由。
- 我的页面增加预览入口，预览结束后保持画面，可重播或返回。
- 定时器在隐藏/卸载时清理，处理后台打断、快速点击与导航失败重试。
- 不将预览计入普通启动完成状态，不新增任何个人数据存储。

## 范围

页面动效发生在微信系统完成代码加载之后。微信自身最早的启动加载画面没有被此代码替换。此版本是视觉体验初稿，后续可按真机体验缩短时长。

## 验证结果

- 37组回归检查通过，包括首次进入、跳过、重复点击、预览重播、等待渲染确认、减少动效、后台打断和导航失败重试。
- 开发者工具默认入口自动进入首页，编译错误0。
- 预览完整画面与重播的早期星轨/完成星图已实际检查。
- JavaScript、JSON、Git空白检查通过；手机上的实际节奏与系统启动衔接仍需真机验收。
