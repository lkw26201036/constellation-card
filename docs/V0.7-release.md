# V0.7.0 · 星光牌阵与答案之书

实现状态：本地开发完成，已完成回归与微信开发者工具模拟器流程验证。未上传本版微信体验包、未提交正式审核；安卓/iOS真机验收待完成。

## 本版功能

- 新抽卡移除“此刻的心情”。经典主题图鉴和已有t1结果保留，新经典主题卡使用无心情的t2版本。
- 首页和抽卡页提供星光牌阵、答案之书入口；首页三个主题直达对应牌阵。今日主签继续快速抽一张，每设备每日一张，其他玩法不占次数。
- 60张原创星光牌、180段牌位文案、60套独立线描插图。图像在本机生成，无第三方图片/字体请求。
- 七张候选牌在展开前确定身份，依次选三张，揭晓前可撤回；三个牌位为当下的你、可能的走向、给你的指引。
- 完整牌库新局排除最近四组结果的最多12张牌，按遇见频次加权随机；主题池不足七张时恢复较早遇见的牌，单局不重复。不是无限不重复，也不宣称随机结果可客观预测未来。
- 归拢展牌、弧形牌扇、选中抬起与小牌落位、浅三角分时翻面、扫光、星图连接、结果淡入。阅读时停止动画。
- 答案之书完整200条原创回应及小行动，1—200固定映射，可手动输入或随机选数；书封开启、书页翻动、正文渐显。同号同文，无吉凶分数。
- 牌阵与书页可收藏、生成海报、分享和回看。牌阵按整组保存，分享保留顺序与牌位；历史各30条，与原有历史分开。
- 支持首次访客、减少动效、跳过动画、后台中断、重播同一牌阵、未完成选择恢复和存储失败重试。
- 经典主题图鉴从卡册继续可达。既有v1/legacy/t1/q1/u1数据与链接保留。

## 数据与版本

- s1：三张有序牌阵，分享参数含三张编号、顺序、主题、星座或通用标记、日期。
- b1：固定答案之书，分享参数含数字、星座或通用标记、日期。
- t2：不附加心情的经典主题卡；t1保持原内容。
- `ritualState`一次存储提交结果、避重计数和草稿清除，避免失败后计数与结果不一致。草稿保留七张候选和有序选择；历史最多30组。
- `answerHistory`保存最近30个不同书页，重复同号移到前面；收藏上限仍是总计50项。
- 问题仅留在用户心里，无输入上传。已有本机调研默认关闭，开启后只新增聚合动作计数，不导出卡牌、所选数字或星座。
- 广告配置位于`miniprogram/config/monetization.js`，默认关闭，不含广告单元ID，不加载广告SDK，所有核心结果免费可读。
