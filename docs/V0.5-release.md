# V0.5 分享与回访阶段

## 已实现

- 每日卡、主签、主题抽卡、测试结果均可生成星座海报；动态排版保留完整文案与底部星座背景。
- 原生大图预览，可长按保存或分享；同页可分享指向原结果的小程序卡片。
- 卡册支持收藏/最近结果/主题图鉴，按四类结果筛选。已遇见的24张主题卡进度独立保存，不因近期历史裁剪丢失。
- 可选本机调研：默认关闭，记录访问、抽卡、测试、分享意图、分享入口访问、海报生成。最多保留30个记录日，可主动复制导出或清除。
- 区分分享点击与打开，不声称点击代表成功；本机数据不代表多用户留存率。

## 限制

- 不上传统计，没有跨设备聚合看板。需要参与体验的用户主动提供导出记录，才能做早期样本分析。
- 海报没有官方小程序码，不能扫码进入。通过同时发送的小程序卡片进入原结果。官方码后续需服务端签发。
- 微信真机保存图片、转发接收仍需验收。
- v1/t1/q1内容保持版本化，新增内容应保留旧解析。

## 验证结果

- 24组回归检查通过，JavaScript与JSON检查通过，git diff --check通过。
- 微信开发者工具完整编译后错误数为0。主签星图、自由抽卡牌面、测试欢迎与题目、卡册以及实际生成的海报已检查。
- 原生测试页已实际选择答案并进入第二题；完整八题提交和返回修改已通过脚本模拟验证。
- 图片真机保存、真实微信转发接收、本机记录的跨设备样本汇总尚未验证或接入。
