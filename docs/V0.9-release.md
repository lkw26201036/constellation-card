# V0.9 产品主线与行动闭环

## 这一版解决什么问题

V0.8 已经具备每日卡牌、星光牌阵、答案之书、双人星图和吉运骰子，但首页更像多个入口的集合，用户不一定能马上理解为什么要继续使用。本版先收拢产品主线，再扩充功能。

核心表达调整为：

> 先照顾此刻，再往前一步。

产品体验围绕三个连续问题展开：

1. 今天的我可以先收下什么方向？
2. 如果和某个人一起，可以从哪里开始靠近？
3. 这句话现在能变成哪一件小事？

## 已完成

- 首页标题改为“先照顾此刻，再往前一步”，增加“一张卡 · 一个小行动 · 一段可以靠近的关系”的价值提示。
- 首页今日行动增加直达吉运骰子的承接按钮，用户可以把今日卡文案交给一件可执行的小事。
- 双人星图的双人入口文案改为“找到一个靠近的角度”，结果页增加下一步提示，并将骰子明确为“小约定”的承接。
- 吉运骰子结果增加下一步提示，强调只完成一件小事，不把骰子包装成吉凶判断。
- 本机调研事件增加 `pair_next_step` 与 `dice_next_step`，继续保持默认关闭、只记录聚合动作、不记录星座组合和具体结果。

## 下一步验证

这一版先不接真实广告。建议用一小批真实用户观察：

- 首页首次点击集中在哪个入口；
- 今日卡到骰子的承接是否被使用；
- 双人星图完成后，是否有人继续摇“小约定”；
- 哪种结果更容易被保存或分享；
- 用户是否愿意第二天再次打开。

当这些路径有稳定使用后，再为“第二视角”“额外一次摇骰”“更具体的小约定”等即时奖励接入激励视频广告。广告继续由 `miniprogram/config/monetization.js` 控制，默认关闭。
