# V0.3 补完整阶段

本版保留原生小程序和本地存储，新增14主题日卡轮换、设备每日抽签一次、卡片详情与分享还原。

## 验收重点

- 同星座同日内容不变，次日更换；所有12个星座可选。
- 抽签后刷新、切换星座、重启都不增加当天次数；隔日恢复。
- 收藏/历史打开完整卡片，旧收藏内容不被覆盖。
- 每日卡与抽签分享打开原来的内容，朋友自己的星座和次数不受影响。
- 缺失或无效链接显示提示。
- 连续访问记录按真实日期计算，间断后重新计数。
- 我的页面能打开反馈与使用说明。
