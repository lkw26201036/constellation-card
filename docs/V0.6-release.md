# V0.6 简约阅读体验

## 本版目标

保留用户认可的深色卡片和十二星座意象，统一全站字体、留白、边框与交互层级。

## 已实现

- 首页、抽卡、详情复用reading-card组件；深松绿卡面、暖白页面和低饱和金色星图。
- 使用本地系统中文衬线标题、系统正文字体；不下载外部字体。
- 移除持续闪动、浮动和大光晕，保留短暂的选牌反馈。
- 首页可直接进入三个主题；新用户明确看到星座选择入口。
- 新增原生线性导航图标，卡册与个人页采用一致的分隔与留白。
- 分享访客优先看到“抽取我的卡片”，自己的结果优先生成海报；主题结果直接进入对应主题。
- 全局减少动效偏好保存到本机，省去洗牌与翻转。
- 未完成测试以q1草稿在本机保存，支持跨页面/重启续答，完成或主动重新开始后清除。存储失败时仍可继续本次答题。
- 数据说明已同步补充草稿与偏好。原有内容和分享版本未改动。

## 边界

本版未接入广告、云端统计或账号同步，也未提交微信正式审核。系统衬线字体在iOS与安卓可能略有差异。真机图片保存及分享接收仍需验收。

## 验证

- 29组回归检查通过：含草稿跨页/重启恢复、完成清除、异常存储、减少动效持久化与主题直达。
- JavaScript、JSON与Git空白检查通过。
- 开发者工具完整编译错误数为0；首页、主签、自由抽卡、卡册、个人页、测试欢迎与题目、详情、海报均已实际检查。
- 新版海报实际生成成功；图片保存及跨设备分享仍需真机验收。
