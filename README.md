# 星座卡牌小程序

V0.3 用于验证每日星座卡、每日抽签、卡片详情和分享流程。

## 运行

1. 微信开发者工具导入本仓库根目录，使用项目配置中的 AppID。
2. 编译后在“今日”选择星座、查看卡片；在“抽签”领取当天结果。
3. 收藏和历史条目可点击查看完整内容。“我的”可查看真实连续访问天数，并进入微信反馈界面。

技术：原生微信小程序，JavaScript / WXML / WXSS。没有 npm 依赖或后端。

## 当前规则

- 每日卡：12 星座共享14个主题，按日期和星座偏移轮换；同日同星座内容一致，主题会重复。每个星座另有独立提醒。
- 免费抽签：每台设备每天一次，切换星座不增加次数。重新打开仍显示当天结果。设备本地零点后可抽新的一张。
- 收藏最多50张，满额时提示先移除；近期抽签历史最多30条，不作为累计抽签次数。
- 连续访问自 V0.3 开始记录，最多保留400天，不补算此前未记录的访问。
- 全部数据保存在设备上，无账号同步；清理数据或改设备时间可能影响本地次数规则。上线若需严格限制，应改成服务端校验。
- 微信原生“意见反馈”入口供用户提交问题，开发者需在微信后台处理；本仓库没有反馈服务器。

## 分享与旧数据

- 新分享进入独立详情页，带类型、内容版本、星座、日期和卡片编号。查看朋友卡片不改变自己的星座，也不消耗抽签次数。
- v1 内容文件发布后应保持原文；新增文案应引入新版本并保留旧解析，确保历史分享可还原。
- 旧收藏和历史保持原始内容，点击时按本地 ID 打开。旧版每日卡分享使用 legacy 固定文案还原。
- 旧版已经发出的抽签链接没有卡片编号，无法恢复原始结果；新版本分享已修复。
- 无效或缺失记录显示空状态。分享海报、测试玩法和主题抽卡在后续版本开发。

## 验证

安装 Node.js 后在仓库根目录执行：

~~~powershell
node tests/run.cjs
~~~

回归检查覆盖12星座跨天内容、每日次数与重启、中文参数编码、所有卡片分享还原、旧收藏、收藏上限、历史去重、连续访问跨年和存储失败。

真机验收：分享给另一台设备确认卡片一致；提交反馈并到微信后台检查；验证进入后台后跨日返回的结果。自动化检查不替代微信真机验收。
