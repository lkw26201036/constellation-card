# 星座卡牌小程序

V0.4：原生微信小程序，JavaScript / WXML / WXSS，无npm依赖。导入本仓库根目录即可开发。

## 本版玩法

- 每日卡：12星座，14主题按日期轮换。
- 今日主签：每台设备每天保留一张；自由抽卡：三个主题共24张，可以反复抽取，不影响主签。
- 心情提示、三张选牌、翻牌动画及跳过动画。
- 抽签和详情底部有十二星座装饰背景，使用原生组件，无外部图片请求。
- 8题趣味充电方式测试、4种结果，支持重做、收藏和分享；同分按类型顺序确定，非心理诊断。
- 收藏最多50张，抽签历史最多30条，测试结果最多20条；无云端同步。

## 验证

运行 node tests/run.cjs。覆盖原有流程和新主题抽卡、测试计分、版本化分享与星座图案。真机分享和微信反馈提交仍需验收。

## 内容版本与打包

v1、legacy、t1、q1分别保留旧日卡/旧主签、主题卡和测试结果的还原规则。发布后不要直接覆盖版本内容。关闭开发工具的忽略未使用文件打包选项，避免新增服务模块被裁剪。
