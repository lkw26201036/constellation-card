# 星座卡牌小程序

当前版本 V1.0，原生微信小程序（JavaScript / WXML / WXSS），无npm依赖。微信开发者工具导入本仓库根目录即可运行。

## V1.0 产品主线与行动闭环

- 首页主线收拢为“今日方向 / 双人关系 / 一件小行动”，标题和入口文案明确表达产品价值。
- 今日卡增加直达星光骰子的行动承接，避免结果停留在阅读层面。
- 双人星图结果增加“小约定”下一步提示，星光骰子结果增加“只完成一件小事”提示。
- 本机调研新增双人结果到骰子、骰子重复探索两个聚合事件，默认关闭，不记录个人答案、星座组合或具体结果。
- 广告仍未接入，后续只在奖励内容明确、用户路径稳定后接入激励视频。

分阶段记录见 [docs/V1.0-release.md](docs/V1.0-release.md)。

## 启动动效

普通默认入口先展示约2秒的星图启动序章：星点亮起、连线、淡出进入首页。支持直接进入；减少动效开启时不强制等待。热返回不重播，分享链接仍直达原结果。

“我的 → 启动动效 → 预览”可反复观看。预览播放完后停留，不自动跳转；不改变正常启动记录。预览支持“首次访客 / 我的星座”切换，不改动真实绑定和本地记录；未绑定时个人预览提示先选星座。

这段动效从小程序页面代码可执行后开始，不能覆盖微信在下载/初始化代码前的系统加载画面。它是品牌序章，不展示虚构的网络加载百分比。

## 首次访客

无有效星座选择时，启动展示十二星光环绕中心的通用品牌星图；首页显示今日灵感卡，可直接抽主签、自由主题卡与测试。不会默认绑定双鱼座，也不展示虚构的专属幸运信息。选择星座后显示个人星图；已抽出的主签与历史卡片保持原内容，绑定不重置每日次数。接收朋友的分享不会绑定对方星座。

## 玩法

- 每日星座卡：12星座，14主题按日期轮换，内容会重复。
- 今日主签：每台设备每天保留一张；自由抽卡：关系沟通/学习工作/自我成长，共24张，可反复抽取，避免连续重复，不影响主签。
- 新抽卡已移除心情选择；旧t1心情卡继续按原文还原。主签保留三选一和翻牌/跳过动画。抽签和详情卡底部有对应星座的原生星图装饰。
- V0.6统一阅读卡片：深松绿、暖白、低饱和金色星图，中文衬线标题和系统正文字体；移除持续闪动和浮动。原生底部导航配套线性图标。
- 首页主题直达：选择主题后直接进入对应自由抽卡；全局“减少动效”在我的页面设置，跨次打开保留。
- 首个趣味测试：8道题、4种充电偏好结果，可重做、收藏、生成海报和分享。未完成的答案与进度保存在本机，可从首页、我的、测试页继续；完成或重新开始清除。非心理诊断，答案不在链接或统计中。
- 卡册：收藏最多50张，抽签近期记录30条，测试结果20条；主题图鉴独立保存已遇见的24张卡片。
- 海报：本机Canvas生成、大图预览、长按保存或分享；另有分享同一结果的小程序入口。图片无官方小程序码。
- 我的：真实连续访问、微信反馈、使用说明、本机调研开关与导出。

## V0.7 星光牌阵与答案之书

- 星光牌阵：60张原创牌面与180段牌位文案，真实七张候选、依序选三张，可撤回；当下/可能走向/行动指引三牌位，完整牌库避开最近四局，主题池不足时恢复最早出现的牌。
- 归拢展牌、抬起落位、浅三角翻面、扫光与星图连接；支持跳过、减少动效、后台中断恢复与重播同一结果。
- 答案之书：200条原创固定回应及小行动，整数1—200输入或随机选数，书封开启与翻页动效，同号同文。输入的问题不采集。
- 整组牌阵/书页可收藏、生成完整海报与分享；历史各30条；经典主题图鉴保留入口。未绑定与断网可使用，核心结果不依赖广告。
- 图像由scripts/generate-arcana-assets.cjs和data/arcana-art.js的60套原创矢量线描生成本地PNG，海报使用同源路径，无外部图片和字体请求。
- 配置miniprogram/config/monetization.js默认关闭，仅预留未来广告位置；没有加载广告SDK。

- 骰子舞台重新调整星盘、骰体、阴影、落地波纹和结果层级，维持原生CSS动效与低资源开销。
- 双人设置与结果按钮统一窄屏比例；版本文案去除“体验版”产品内提示。

## V0.8 双人星图与吉运骰子

- 双人星图：选择双方星座与心动探索/恋爱相处/朋友相处，七选三并揭晓“连接、差异、靠近”。结果用交流节奏、情绪回应、行动步调三个维度和一句关系总结，不显示百分比。
- 双人星图动画从两束星光相遇开始；选填昵称与性别描述只在本机，不进入分享。
- 吉运骰子：六面星座骰对应出发、松弛、表达、尝鲜、整理、温暖；单人60条建议、双人60条小约定，点数不分吉凶。
- 骰面含星点和星图，投掷包含翻滚、弹跳、落地、点数亮起和结果渐显；支持跳过与减少动效。双人结果可从牌阵联动并回看。
- 双人和骰子支持收藏、历史、海报、分享预览；接收分享不会覆盖自己的星座。
- V0.8版本说明见 docs/V0.8-release.md。

## 数据与调研

数据仅在本机，没有登录或云端同步。主签次数可受清理存储、改变设备日期影响；服务器校验尚未接入。

本机调研默认关闭，开启后按日期记录操作次数，最多30个记录日，可随时停止或清除。分享意图与接收链接打开分开计数。报告不含个人身份、选择的星座、逐题答案及完整分享链接，不作为全体用户留存率。早期样本需用户主动导出提供。

## 内容与打包

v1/legacy保留旧日卡和主签，t1为旧心情主题卡，t2为新无心情主题卡，q1为测试结果，u1为通用今日灵感卡，s1为有序三张牌阵，b1为固定答案书页。已发布内容不要原地覆盖，新内容引入新版本，保留旧还原规则。旧分享缺少卡片编号的抽签链接无法恢复原抽签。

项目关闭ignoreDevUnusedFiles，避免服务模块在开发打包中被裁剪。无AppSecret等服务端密钥。
