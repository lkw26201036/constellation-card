# 星座卡牌小程序

这是一个面向微信小程序的星座卡牌产品，第一阶段用于验证每日星座卡、轻量神谕抽签和分享传播。

## 当前状态

- 版本：V0.2 项目骨架
- 开发模式：原生微信小程序
- 语言：JavaScript、WXML、WXSS
- AppID：已写入本地项目配置
- 后端：暂未接入，当前使用本地模拟数据

## 本地打开

1. 打开微信开发者工具。
2. 选择“导入”或“添加项目”。
3. 项目目录选择本文件所在目录。
4. AppID 使用项目配置中的 AppID。
5. 选择“微信开发者工具”项目类型。
